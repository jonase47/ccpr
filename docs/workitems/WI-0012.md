scripts/memory-sync.sh line 244 uses ${NS,,} -- lowercase expansion, a bash 4 construct. macOS ships /bin/bash 3.2.57, which answers "bad substitution".

The line sits inside a die message: promote without a repo-relative destination is supposed to print a usage hint, and instead the hint itself fails. The error path errors.

Confirmed 18.08.2026 on bash 3.2.57 (arm64-apple-darwin25). Pre-existing -- it predates the artifact-gate work (WI-0004) and was found while reviewing it; the gate refactor added no new path to cmd_promote, which remains the only call site.

Fix is a tr or an inline lowercase that works on 3.2. Worth checking the same file and the rest of scripts/ for other bash-4-only constructs in the same pass: ${x,,}, ${x^^}, mapfile, readarray, associative arrays, and local -n. The repo has been bitten by the 3.2 default before (instinct-check.sh aborted on an empty-array expansion under set -u).
