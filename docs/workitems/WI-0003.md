The 5 KB / 150-line cap is documented in the template header and enforced by /cleanup, but nothing triggers it. doc-volume-check.sh does not help: its thresholds are 25/40/50 KB, five times the cap. hooks/ exists and settings.json already wires SessionStart, SessionEnd and PreToolUse. Field observation 18.08.2026: one full skill run took this repo's own HANDOVER from 3785 to 4806 bytes (94 percent of cap) and only stayed under by replacing blocks rather than appending; a later run needed a manual compaction pass. Follow the two-tier check-location pattern settled with ADR-0009.
